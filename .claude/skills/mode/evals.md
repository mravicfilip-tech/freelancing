# mode evals

1. "/mode studio" on an Opus high session. Prints the studio row, no model menu line.
2. "/mode light" on an Opus high session. Prints the light row and one line to pick Sonnet at low.
3. "/mode banana". One line listing the five modes, nothing else.
4. After "/mode research", a request to read three transcripts spawns `read` helpers, not general-purpose.
