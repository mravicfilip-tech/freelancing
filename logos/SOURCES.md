## Not included: NOAH

No SVG for NOAH (noah.com, the stablecoin payments company) could be sourced.
Their GitHub org (`noah-labs`) publishes no brand assets, and this session's
network egress policy blocks every other host that carries them (noah.com,
docs.noah.com, brandfetch, worldvectorlogo, seeklogo, Wikimedia, the Iconify
API). Only `raw.githubusercontent.com`, GitHub git, and the npm/PyPI registries
are reachable. Grab it from https://noah.com or ask NOAH for brand assets.

## Notes

* `anthropic-icon.svg` and `privy-icon.svg` had `currentColor`/no fill in the
  source; explicit brand fills (`#181818`, `#010110`) were set so they render
  standalone. Change the `fill` for use on dark backgrounds.
* Privy also ships a white variant (`privy-logo-white.svg`) in the same repo.
* These are third-party trademarks. Usage is governed by each company's brand
  guidelines, not by the license of the repository the file came from.
