# Rules

## Do
- Use the supplied logo files. Wordmark and icon are final art.
- Dark lockup on Night. Light lockup on Off-white.
- White bars only inside an Ignition or Night tile (app icons, avatars).
- Keep one bar-width of clear space around any lockup.
- Icon alone under 200px wide. Wordmark never in a circle.
- One primary gradient button per view.
- Section numerals in Michroma, in Flame.

## Don't
- Never stretch, squash or rotate the icon or wordmark.
- Never retype the wordmark in any font.
- Never place the logo on a busy background or a photo.
- Never reverse the gradient or run it vertically.
- Never use the gradient as a page background.
- Never add drop shadows, outlines or bevels to the logo.
- Never mix the icon's gradient bars with a light-mode navy wordmark on a dark ground, or the silver wordmark on a light ground.
- No stock photos, no emoji, no Inter or Roboto or Arial, no colored left-border cards, no em dashes.

## Accessibility floor
- Body text 4.5:1. Large text 3:1. Use `--ml-fg-muted` per theme, not a lighter gray.
- Real `<button>` and `<a href>`. `<label>` on every input. Focus rings stay on.
- Touch targets 44px minimum.
