# Portfolio case studies

The five case studies from [filip-portfolio](https://github.com/mravicfilip-tech/filip-portfolio),
copied verbatim from `src/data/content.js` with their images. Each folder holds the
cover, three screens, the client logo where one exists, and a README with the copy.
`case-studies/case-studies.json` is the same data in machine-readable form, with
image paths relative to each project folder.

| Case study | Category | Region |
|---|---|---|
| [BRP – Dealer Platform & Marketing Center](case-studies/brp/README.md) | Enterprise | North America |
| [Allstate – Agent Marketing Tooling on AMS](case-studies/allstate/README.md) | Design System | US |
| [Varntix – Fintech Product Design](case-studies/varntix/README.md) | Fintech | EU |
| [HFDX – Decentralized Trading Platform](case-studies/hfdx/README.md) | Web3 | EU |
| [Lyrie – Cybersecurity Platform & Brand Identity](case-studies/lyrie/README.md) | Cybersecurity | EU |
