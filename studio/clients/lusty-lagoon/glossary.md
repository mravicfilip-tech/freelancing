# Glossary

UI terms for this client. Copy uses these words and no others for the same thing. `/uireview`
checks copy against this file. Add a term the first time the UI needs a new one.

| Term | Means | Never say | Where used |
|---|---|---|---|
| Lobby | The signed in home with promos, game rows and live wins | Dashboard, Home | Sidebar, top of the product |
| Wallet | Where money moves in and out, with Deposit, Gift card, Withdraw and Tip | Cashier, Bank | Sidebar, wallet tabs |
| Account balance | The player's current funds, shown in the top bar | Credits, Coins | Top bar |
| Send to agent | Filip to add, what an agent is and what is sent | Transfer | Sidebar |
| Partner platform | A game platform reached through Lusty Lagoon, such as Juwa City or Game Vault | Partner site, Provider | Landing page |
| Rank | The player's loyalty level, Bronze then Silver and up | Tier, Badge | Sidebar |
| Withdrawal | Money leaving the balance, the noun | Withdraw, as a noun | History, receipt |
| Network | The chain a coin moves on, such as Tron (TRC20) | Chain, Protocol | Send and Details steps |
| Destination tag | The XRP memo that matches a deposit to an account | Memo, Tag ID | XRP deposit |
| Summary, Receipt | The right column, before and after the result | Order, Invoice | Wallet |

## Verbs

Buttons name what happens. One verb per action across the app.

| Action | Label | Never |
|---|---|---|
| Move to the next step of a payment | Continue | Next, Proceed |
| Pay a card or PayPal deposit | Confirm and pay, Continue to PayPal | Pay now, Submit |
| Say a coin or bank transfer has been sent | I've sent it, I've sent the transfer | Done, Finish transaction |
| Send a withdrawal | Confirm withdrawal | Withdraw money, Finish transaction |
| Start again after a result | Make another deposit, Make another withdrawal | Reset, New |
| Copy a value | Copy | Copy to clipboard |

## Errors

An error says what went wrong and what to do next, in one sentence.
