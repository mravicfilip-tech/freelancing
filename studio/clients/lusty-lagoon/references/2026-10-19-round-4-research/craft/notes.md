Captured 2026-10-19. Dribbble shot pages were read through a headless browser and the main image saved as webp. The site numbers below are real computed styles read from the live pages. Dribbble pixel values are estimates read off the image and are marked "about". Dribbble shot dates were not verifiable from the pages, but the shot ids (25M to 27M) are the current range.

Honest read first. Of the ten casino shots, only Hyde, Oval and BetOnline come near the two accepted references. The rest are loud, saturated or mockup staged, and are kept as cheap tell evidence. The strongest craft lessons come from the four product sites.

## Techniques

1. Hairline edge ladder. Three edge strengths for three depths. `border:1px solid rgba(255,255,255,.05)` flat, `.08` panel, `.12` raised. Source Linear card CSS.
2. Panel fill one step off the ground. `background:#0f1011` on a `#08090a` page, with `.03` white overlay on the card. Source Linear.
3. Top highlight line that fades at the ends. `.panel::before{content:"";position:absolute;inset:0 0 auto 0;height:1px;background:linear-gradient(90deg,transparent,rgba(255,255,255,.18) 50%,transparent)}`. Raycast uses the simpler `box-shadow:inset 0 1px 0 rgba(255,255,255,.1)`. Source Raycast, Hyde.
4. One soft radial light per panel. `background:radial-gradient(60% 50% at 50% 0%,rgba(168,85,247,.16),transparent 70%),#0d0d10`. Raycast measured `radial-gradient(75% 75% at 50% 91.9%,#121212,#0d0d0d)` for a neutral card. Source Raycast, Hyde.
5. Grain over lights. `.grain::after{content:"";position:absolute;inset:0;background:url(noise.png);opacity:.05;mix-blend-mode:overlay;pointer-events:none}`. Keeps radial lights from banding. Source Raycast hero, Hyde Fear and Greed.
6. Glass on pinned bars. `background:rgba(0,0,0,.6);backdrop-filter:blur(36px);border:1px solid rgba(142,140,144,.2);box-shadow:inset 0 .5px 0 rgba(255,255,255,.3)`. Source Raycast.
7. Ring as shadow, not border. `box-shadow:0 0 0 1px rgba(255,255,255,.08)`. Layout never shifts when the ring grows on hover. Source Vercel buttons.
8. Button fill, edge and inner hairline. `box-shadow:0 0 0 1px rgba(0,0,0,.5),inset 0 1px .4px rgba(255,255,255,.9),inset 0 -1px .4px rgba(0,0,0,.2)`. A 1px inset line is an edge, not a gloss. Source Raycast Download button.
9. Pressed state. `transition:transform .1s cubic-bezier(.23,1,.32,1);active:scale(.97)`. Cloudflare animates `transform` over 0.06s and Replit drops opacity to 0.75 on hover. Source Raycast, Cloudflare, Replit.
10. Focus ring. `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[#ff8a3d]`. Replit uses a 1px auto outline. Source Replit.
11. Tabular figures. `font-variant-numeric:tabular-nums;font-feature-settings:"tnum","cv01","ss03"`. Linear ships `cv01` and `ss03`, Vercel `ss11`. Source Linear, Vercel, Cybet table.
12. Count up and odometer. Count up with `animate(0,value,{duration:.9,ease:[.23,1,.32,1]})` and roll digits with `transform:translateY(-n*1em)` at `.5s cubic-bezier(.23,1,.32,1)`. Hyde shows the tile form. Easing from Raycast.
13. Live pulse. `.live::after{animation:ping 1.6s cubic-bezier(0,0,.2,1) infinite}` with `@keyframes ping{75%,100%{transform:scale(2.2);opacity:0}}`. Dot is 6px, colour only for status. Source Tailwind animate-ping, Cybet live dot.
14. Media card hover without layout shift. `.card{aspect-ratio:4/5;transition:transform .2s cubic-bezier(.23,1,.32,1),box-shadow .2s}.card:hover{transform:translateY(-2px);box-shadow:0 0 0 1px rgba(255,255,255,.16),0 12px 32px rgba(0,0,0,.4)}`. Only transform and shadow change. Source Raycast card transitions.
15. Motion timing. Under 200ms for controls, 400ms for opacity fades. `0.16s cubic-bezier(.25,.46,.45,.94)` Linear, `0.15s cubic-bezier(.4,0,.2,1)` Vercel, `0.2s cubic-bezier(.23,1,.32,1)` Raycast.
16. Skeleton shimmer. `background:linear-gradient(90deg,rgba(255,255,255,.04) 25%,rgba(255,255,255,.09) 50%,rgba(255,255,255,.04) 75%) 0 0/200% 100%;animation:sh 1.4s linear infinite`. Same radius as the real tile. House pattern.
17. Display type and caps labels. `font-size:64px;font-weight:510;letter-spacing:-.022em` for heads (Linear), `-.06em` at 56px (Vercel). Labels `font:500 12px/1 mono;letter-spacing:.12em;text-transform:uppercase;color:#62666d` (Raycast, Linear).
18. Spacing rhythm. 4px base, 16px gaps between panels, 20px inner padding, radius scale 6, 8, 12, 16. `gap-4 p-5 rounded-xl`. Source Hyde gaps, Linear radius ladder.

## Cheap tells

1. More than one saturated hue in tiles on one screen. Count distinct hues over 40 percent saturation in the game grid. Premium shots stay at one or two (RushDrop has eight).
2. Purple to pink or cyan to pink gradient fills on buttons. Check `background-image` on every button for two hues.
3. Outer glow on buttons or cards. Search box shadows with a blur over 12px and a coloured alpha over .3.
4. Text under 12px, or grey text under 4.5 to 1 against its panel. Run the contrast check on every secondary label.
5. Panel edges that differ, and mixed control heights in one row. More than three different border colours or radii on one screen. Count the distinct values.
6. Floating 3D coins, chips or cards beside UI. Any decorative image overlapping a panel edge.
7. Mockup staging inside the product. A laptop or tablet frame, or a bezel, around the UI.
8. Every panel lit. A glow behind more than one panel in the same viewport, or a lit panel next to another lit panel.
9. Numbers set in a proportional font so columns jitter. Check `tabular-nums` on balances, odds and the bet table.
10. Heavy bold caps in display type with loose tracking above 0, or a script and brush face for headlines. Check headline tracking is negative.
