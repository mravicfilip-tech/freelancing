# milan-peulic

Milan Peulic. The work so far is his portfolio deck, rebuilt from the Diversify general portfolio.
The deck lives in `milan-peulic-portfolio/` at the repo root.

## Brand

- Colours are the Diversify deck's, kept as they were. Page black `#000000`, footer band
  `#1F1F1F`, header bar `#FFFFFF`, header rule `#B0B0B0`, header tile `#262B35`.
- Type. Manrope Regular for body copy, Manrope Medium for the header name, tagline and footer,
  Manrope SemiBold and Bold for labels. The cover name and the page 2 statements use a light
  display face that is not Manrope and is not identified yet.
- Logo. None on file. The MP monogram in Manrope Medium, white, in the header tile and the cover
  orb is a placeholder, not an accepted mark.
- Voice. First person singular. "I", never "we".

## Rules that never bend

None set by the client yet.

## Accessibility

WCAG 2.2 AA as the default bar. Nothing reviewed yet.
